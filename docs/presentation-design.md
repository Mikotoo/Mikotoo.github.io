# Mikotoo 展示站：内容与布局

## 面向谁

首页面向第一次访问的读者：想了解研究方向、查看分析项目、阅读技术文章或寻找代码。页面首先回答“你关注什么、这里有什么值得看、下一步去哪里”。维护者的构建命令、目录约定、同步与部署说明保留在 README 和 docs/，不进入访客浏览路径。

## 首页结构

不设置完成率、任务状态、文件数、构建时间等仪表盘元素。首页不逐项解释技术栈或维护流程。

## 视觉语言

- 浅色：暖白背景、森林绿主色、少量赭色小标题。
- 深色：深绿色背景，使用浅绿和暖白确保文字层级。
- 大标题用系统衬线字体；正文用系统无衬线字体，避免外部字体请求。
- 卡片以细边框、留白与主题标签组织信息，不堆叠装饰或大面积阴影。
- 首页插图为原创抽象 SVG，仅作装饰，不代表真实实验结果。
- 桌面项目卡片两列、阅读卡片三列；小屏单列。手机顶部保留主导航、搜索、主题和文章目录按钮。
- 支持键盘焦点与减少动态效果偏好。

## 文案边界

研究方向与项目说明来自现有 README 和文章，不添加未经确认的学历、任职、奖项、发表状态或定量成果。第三方论文复现仍清晰标注为论文复现；项目卡片不会把它包装成原创成果。

`Rscript` 的公开 GitHub 地址在设计检查时返回 404，因此展示卡片隐藏该外链（`showRepository: false`），仍保留站内介绍与技术文档入口。

## 后续编辑

- 首页的大标题、简介、方向入口与结尾：`content/pages/index.md`。

维护说明只留在仓库文档。新增展示页面时不放构建命令、提交步骤或源目录结构。
